# Silicon Racer brand archive

The selected **San Francisco Soapbox Club** direction uses forest, vermilion, cream and fog mint. That identity is now integrated into the application: the landing pairs the badge and accessible Start/Join controls with a live 3D race scene. The generated wide splash is retained as art direction, not used as a flattened interactive screen.

The original exploration, splash and badge-generation documents record earlier production stages. Their statements about pending integration are historical. The separate **v2 game-art work** remains a different workstream; this archive does not claim that artwork is finished or integrated.
